# Digital Design Fundamentals

A comprehensive collection of Digital Design Fundamentals implemented in **Verilog** and **SystemVerilog** using multiple modeling styles and verified with **Icarus Verilog**.

## Objectives

* Learn Digital Design from the fundamentals.
* Implement combinational circuits using different HDL modeling styles.
* Compare Verilog and SystemVerilog implementations.
* Verify designs using self-contained testbenches.
* Simulate using Icarus Verilog.
* Analyze waveforms using GTKWave.

## HDL Modeling Styles

### Verilog

* Behavioral Modeling
* Dataflow Modeling
* Structural Modeling

### SystemVerilog

* Behavioral Modeling
* Dataflow Modeling
* Structural Modeling
